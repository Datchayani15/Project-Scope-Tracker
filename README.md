# Project Scope Tracker

## Overview
Project Scope Tracker is a web-based application designed to help teams plan, organize, and monitor project tasks and milestones effectively. It supports progress tracking, task management, and timeline control, making project execution simple and efficient.

This repository contains the complete source code of the system, including frontend and backend components.

## Features
- Add, update, and delete project tasks
- Track milestones and deadlines
- Visual progress monitoring
- Simple and user-friendly interface
- Database support for storing task information

## Technologies Used
- HTML
- CSS
- JavaScript
- Backend (Flask)
- Database (SQLite)

## Getting Started
### Clone the Repository
git clone https://github.com/your-username/Project-Scope-Tracker.git

### Run the Project
Open the `index.html` file in any browser or run using a local server environment.
